# Regression Metrics

| Метрика | Формула | Свойства |
|---------|---------|----------|
| **MAE** | $\frac{1}{N}\sum\|y - \hat{y}\|$ | Те же единицы, робастна |
| **MSE** | $\frac{1}{N}\sum(y - \hat{y})^2$ | Штрафует большие ошибки |
| **RMSE** | $\sqrt{MSE}$ | Те же единицы, чувствительна к выбросам |
| **R²** | $1 - \frac{SS_{res}}{SS_{tot}}$ | Доля объяснённой дисперсии; <0 = хуже среднего |
| **MAPE** | $\frac{100}{N}\sum\|\frac{y-\hat{y}}{y}\|$ | % ошибка, ломается при $y \approx 0$ |

## Ranking (кратко)

| Метрика | Зачем |
|---------|-------|
| **NDCG** | Ранжирование с учётом позиции |
| **MAP** | Mean Average Precision |
| **MRR** | Mean Reciprocal Rank — первый правильный ответ |

## Если спросят

- **Зачем:** MAE/RMSE — в единицах $y$; R² — доля объяснённой дисперсии.
- **Когда ломается:** MAPE при $y\approx 0$; R² на маленькой выборке врёт.
- **Путают с:** classification F1 / accuracy.
- **Фраза:** R² < 0 — модель хуже константы «среднее».
