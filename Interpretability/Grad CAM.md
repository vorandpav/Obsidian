# Grad CAM

## CAM

CAM (Class Activation Mapping) — метод визуализации, который позволяет понять, какие области изображения повлияли на предсказание модели. Он требует модификации архитектуры сети, добавляя глобальный average pooling перед полносвязным слоем. Grad-CAM расширяет эту идею, используя градиенты для вычисления весов активаций, что позволяет применять метод к уже обученным моделям без изменения их структуры.

## Идея

Grad-CAM (Gradient-weighted Class Activation Mapping) — метод визуализации для интерпретации решений свёрточных нейросетей. Показывает, какие области входного изображения повлияли на предсказание класса $c$.

Алгоритм состоит из трёх шагов:

1. Получаем активации последнего свёрточного слоя $A^k_{ij}$ для каждого фильтра $k$ на позиции $(i, j)$. То есть знаем насколько сильно каждый фильтр реагирует на разные части изображения.
2. Вычисляем градиенты класса $c$ по этим активациям:
   $$
   w^k_c = \frac{1}{Z} \sum_i \sum_j \frac{\partial y^c}{\partial A^k_{ij}}
   $$
   где $Z$ — нормализация по всем фильтрам и пикселям. Теперь мы понимаем, какие активированные фильтры были важны для предсказания класса $c$.
3. Строим карту значимости (heatmap):
   $$
   \text{Grad-CAM}(c) = \text{ReLU}\left(\sum_k w^k_c A^k\right)
   $$

## Если спросят

- **Зачем:** визуализировать, на что смотрит модель при классификации.
- **Когда ломается:** если в сети нет свёрточных слоёв (например, в Transformer).
- **Путают с:** CAM (Class Activation Mapping) — Grad-CAM не требует модификации архитектуры.
- **Фраза:** Grad-CAM — это взвешенное по градиентам усреднение карт активаций.
