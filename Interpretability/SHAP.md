# SHAP

Shapley Additive Explanations

Значения Шэпли - это способ оценки вклада каждого признака в результат модели. Формула заключается в том, чтобы определить средний вклад признака во все возможные комбинации признаков:

$$
\phi_i = \sum_{S \subseteq F \setminus \{i\}} \frac{|S|!(|F|-|S|-1)!}{|F|!} \left(f_{S \cup \{i\}}(x_{S \cup \{i\}}) - f_S(x_S)\right)
$$

Введём условия:
1. Локальную модель, которая позволяет разложить функцию на базовый вклад и взвешенные вклады каждого признака: $f(x) = g(x') = \phi_0 + \sum_{i=1}^{M} \phi_i x_i^{'}$
2. Условие нулевого вклада: $x_i^{'} = 0 \Rightarrow \phi_i = 0$
3. Если значимость $i$-го признака для первой модели больше, чем для второй, то разница между предсказаниями должна быть также больше:

$$
f_x^{'}(z^{'}) - f_x^{'}(z^{'}\setminus i) \geq f_x(z^{'}) - f_x(z^{'}\setminus i) \Rightarrow \phi_i(f^{'},x) \geq \phi_i(f,x)
$$

Теорема заявляет, что значения Шэпли являются единственным  решением условий 1-3.

То есть на практике получаем:
* $\phi_0$ задаётся как среднее значение по выборке.
* $\phi_i$ задаётся как средняя разница между предсказаниями модели с и без $i$-го признака.
* очень удобно представлять значение Шэпли как предсказание дерева, которое принимает вектор с missing values. [[Decision tree]]

## Если спросят

- **Зачем:** средний вклад признака по всем коалициям; единственное решение аксиом 1–3.
- **Когда ломается:** $2^{|F|}$ коалиций; зависимые признаки — интервенция $x_S$ сомнительна.
- **Путают с:** LIME и с impurity importance деревьев.
- **Фраза:** $\phi_i$ — средний прирост $f$ при добавлении $i$ во все подмножества.
