# Importance Estimation

1. Drop feature importance - обучение модели, убирая каждую из фич. Требует очень много попыток.
2. Permutation importance - обучение одной модели, перемешивание значений в пределах одного признака, анализ изменений качества результатов.
3. В линейных моделях анализируется значение $w_i$, при условии нормализации данных, большее $w$ означает больший вклад признака. Коэффициент:

$$
w_i \cdot \frac{std(x_i)}{std(y)}
$$

показывает на сколько среднеквадратических отклонений (std) изменится целевая переменная $y$, если значение признака $x_i$ изменится на одно среднеквадратическое отклонение.
4. Использование регуляризации позволяет модели при обучении убирать незначимые признаки.
5. Information gain - используется в деревьях решений, показывает насколько хорошо признак разделяет данные во всех узлах дерева. Даёт искажённые результаты в пользу признаков с большим количеством уникальных значений.
6. [[LIME]]

## Если спросят

- **Зачем:** drop / permutation / $|w|$ после scale / L1 / information gain.
- **Когда ломается:** IG любит high-cardinality; веса без нормировки несравнимы.
- **Путают с:** причинностью: важность $\neq$ causal.
- **Фраза:** permutation — мешаем один столбец, смотрим падение качества.
