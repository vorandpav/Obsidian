## Основные классы (от лучшего к худшему)

```
O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2^n) < O(n!)
```

| Класс | Пример | n=10⁶ |
|-------|--------|-------|
| O(1) | Hash lookup | 1 |
| O(log n) | Binary search | ~20 |
| O(n) | Linear scan | 10⁶ |
| O(n log n) | Merge sort | ~20·10⁶ |
| O(n²) | Nested loops | 10¹² ❌ |
| O(2^n) | Subsets brute force | 💀 |

**Правило:** n ≤ 10⁶ → O(n log n) ок. n ≤ 10³ → O(n²) ок. n ≤ 20 → O(2^n) ок.

## Как оценить сложность кода

### 1. Вложенные циклы
```python
for i in range(n):       # O(n)
    for j in range(n):   # O(n)
        ...
# → O(n²)
```

### 2. Деление пополам
```python
while lo < hi:
    mid = (lo + hi) // 2
    ...
# → O(log n)
```

### 3. Рекурсия — Master Theorem

$T(n) = a \cdot T(n/b) + O(n^d)$

| Условие | Сложность |
|---------|-----------|
| $d < \log_b a$ | $O(n^{\log_b a})$ |
| $d = \log_b a$ | $O(n^d \log n)$ |
| $d > \log_b a$ | $O(n^d)$ |

**Примеры:**
- Merge sort: $a=2, b=2, d=1$ → $d = \log_2 2$ → **O(n log n)**
- Binary search: $a=1, b=2, d=0$ → **O(log n)**

### 4. Рекурсия с ветвлением
```python
def fib(n):
    if n <= 1: return n
    return fib(n-1) + fib(n-2)
# → O(2^n) без мемоизации, O(n) с мемоизацией
```

## Вопросы на собесе

**O(n + m) vs O(nm)?**
> n+m — два последовательных прохода. nm — вложенные циклы по обоим.

**Почему Dijkstra O((V+E) log V)?**
> Каждая вершина — push/pop в heap O(log V), E рёбер.

**Сложность сортировки сравнением?**
> Нижняя граница Ω(n log n).

**Как быстро оценить на собесе?**
> Сколько раз тело цикла выполнится? Есть ли деление пополам? Рекурсия на сколько веток?
