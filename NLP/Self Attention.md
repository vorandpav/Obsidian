# Self Attention

## Переход от [[Attention]] к Self-Attention

В Attention мы передавали в декодер вектор $c_j$, содержащий информацию о значимых токенах.Однако этот же алгоритм можно
использовать и в кодере, чтобы каждый токен мог учитывать контекст других токенов. Это и есть Self-Attention.

## Self-Attention в кодере

![[Self Attention Encoder.png]]

Как и в [[RNN]] сначала мы вычисляем скрытое состояние кодера $h_t^{enc}$ для каждого токена. Далее берём каждый
вектор $h_t^{enc}$ и применяем к нему функцию $s(h^{enc}_t, h^{enc}_l)$, которая будет определять важность $l$-го токена
для $t$-го токена. Получаем веса $w_l = s(h^{enc}_t, h^{enc}_l)$. Применяем softmax, чтобы получить
коэффициенты $\alpha_l$ и вычисляем контекстный вектор $c_t$ как взвешенную сумму скрытых состояний кодера. Теперь
конкатенируем в $a_t = [h_t^{enc}; c_t]$ и умножаем на матрицу $W$ для получения нового скрытого состояния
кодера $H_t^{enc} = W \cdot a_t$. Таким образом, каждый токен учитывает контекст других токенов.

Так как у нас $h_t^{enc}$ зафиксированы - это вычисление можно сделать параллельно для всех токенов, что значительно
ускоряет обучение по сравнению с [[RNN]].

## Self-Attention в декодере

![[Self Attention Decoder.png]]

Применим Self-Attention декодере, как отдельную модификацию RNN (без связки с кодером). Для первого токена декодера
выполняем стандартный проход через RNN, потому что не на что строить Attention. Для второго токена декодера тоже
применяется стандартный проход через RNN, так как внимание даст единственный максимум для прошлого состояния, то есть
вернёт h_1^{dec}.

Для третьего токена декодера мы уже можем использовать Self-Attention, так как у нас есть два скрытых состояния
h_1^{dec} и h_2^{dec}. Таким образом, для каждого токена декодера мы можем учитывать контекст предыдущих токенов.

Такой подход не получится распараллелить, так как для каждого токена декодера нужно знать скрытые состояния предыдущих
токенов.
