# Gradient Problems

Проблемы с градиентами — основное ограничение рекуррентных нейросетей (RNN) при обучении на длинных последовательностях. Возникают из-за глубокого умножения матриц весов в рекуррентных слоях при обратном распространении ошибки по времени (BPTT).

## Vanishing Gradient

**Проблема:** Градиенты экспоненциально уменьшаются при обратном распространении по времени, из-за чего:
- Веса ранних слоёв почти не обновляются.
- Модель не может учитывать длинные зависимости (например, связь между первым и последним словом в последовательности).

**Причина:**
Производная активаций (sigmoid, tanh) ограничена по модулю. При умножении на матрицу весов $W_{hid}$ с нормой $< 1$ градиент стремится к нулю:
$$
\frac{\partial \mathcal{L}}{\partial W} \propto \prod_{t=1}^T \frac{\partial h_t}{\partial h_{t-1}} \approx 0 \quad \text{при больших } T
$$

**Решения:**
- **LSTM/GRU:** Используют gates (forget, input, output) и cell state для передачи градиента напрямую.
- **Skip connections:** Прямые связи между слоями (аналогично ResNet).
- **Инициализация весов:** Orthogonal или Xavier инициализация.
- **Активации:** ReLU (но требует осторожности с exploding gradient).

## Exploding Gradient

**Проблема:** Градиенты становятся слишком большими, из-за чего:
- Веса обновляются хаотично.
- Модель не сходится (появляются NaN в весах).

**Причина:**
Норма матрицы весов $W_{hid} > 1$. Градиенты растут экспоненциально:
$$
\frac{\partial \mathcal{L}}{\partial W} \propto \prod_{t=1}^T W_{hid} \to \infty
$$

**Решения:**
- **Gradient Clipping:** Ограничение нормы градиента (например, $ |g|| \leq \text{threshold}$).
- **Batch Normalization:** Нормализация активаций между слоями.
- **Weight Regularization:** L1/L2 регуляризация.
- **LSTM/GRU:** Gates помогают контролировать поток градиента.

## Если спросят

- **Зачем:** без решения этих проблем RNN не может обучаться на длинных последовательностях.
- **Когда ломается:** при глубоких рекуррентных связях (большое $T$).
- **Путают с:** градиентным спуском — это не метод оптимизации, а проблема в вычислении градиентов.
- **Фраза:** vanishing/exploding — это две стороны одной медали: экспоненциальное изменение градиента при умножении матриц.
