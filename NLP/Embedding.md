# Embedding

Эмбеддинг - процесс преобразования токенов в векторы.

1. One-hot encoding - вектор, содержащий только одну единицу, соответствующую токену. Минусы: разряженность вектора, не учитывается сходство слов.

2. GloVe - метод получения эмбеддингов на основании контекста слова. Сначала строим матрицу $T \times T$ - сколько раз встречается пара слов в корпусе. Воспользуемся симметричностью матрицы - мы можем снизить её размерности с помощью разложения по сингулярным числам. В итоге получаем матрицу $T \times d$ - эмбеддинги слов. Минусы: не учитывается порядок слов, сложность вычислений.

3. Word2Vec - нейросетевой метод получения эмбеддингов на основании контекста слова. На вход подаём one-hot вектор слова - далее идёт слой $T \times d$, где $d$ - размерность эмбединга - учим сеть классификации на слово, которое стоит рядом с ним. В процессе обучения учитывается частота слова в корпусе, предполагается, что частые слова - служебные и не несут информации. Также решается проблема softmax над большим словарём - вместо предсказания вероятности всех слов используется бинарная классификация с negative sampling.

## Если спросят

- **Зачем:** токен → плотный вектор; GloVe из совместных частот, Word2Vec — предсказать соседа.
- **Когда ломается:** one-hot не ловит сходство; GloVe/W2V — нет порядка и OOV.
- **Путают с:** токенизацией.
- **Фраза:** эмбеддинг — сжатый вектор токена из контекста.
