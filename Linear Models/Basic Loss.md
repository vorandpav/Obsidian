# Basic Loss

## MSE loss:
* позволяет вычислить наилучшую линейную несмещённую оценку для $w$, используя [[Gauss Markov Theorem]];
* дифференцируемая функция, что позволяет использовать градиентные методы для оптимизации;
* чувствительна к выбросам, что может привести к переобучению.

## MAE loss:
* менее чувствительна к выбросам, чем MSE loss;
* не дифференцируемая функция, но можно использовать решение:

$$
\frac{d}{dw} |w| = \begin{cases}
1 & \text{if } w > 0 \\
-1 & \text{if } w < 0 \\
0 & \text{if } w = 0
\end{cases}
$$


## Huber Loss

Компромисс MSE + MAE: маленькие ошибки — квадрат, большие — линейно (порог $\delta$).

## Если спросят

- **Зачем:** MSE дифференцируема и даёт BLUE; MAE меньше дергается от выбросов.
- **Когда ломается:** MSE — выбросы тянут оценку; MAE — излом в нуле.
- **Путают с:** L2/L1 регуляризацией (штраф на веса, не на остатки).
- **Фраза:** MSE квадратит ошибку, MAE берёт модуль.
