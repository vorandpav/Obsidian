# Maximum Likelihood Estimation

Метод максимального правдоподобия - это метод нахождения оценки параметров модели, которая максимизирует вероятность наблюдаемых данных.

То есть воспользуемся [[Logistic regression]] и найдём такой вектор $w$, который максимизирует вероятность наблюдаемых данных.

При условии нашей выборки получается:
* если $y^{(i)} = 1$, то $P(x,y|w) = \sigma(w^T x^{(i)}) = \sigma(M^{(i)})$
* если $y^{(i)} = -1$, то $P(x,y|w) = 1 - \sigma(w^T x^{(i)}) = \sigma(M^{(i)})$

Таким образом, логарифм правдоподобия:

$$
log\mathcal{L}(w|X,Y) = \sum_{i=1}^n \log \sigma(M^{(i)}) = -\sum_{i=1}^n \log (1 + e^{-M^{(i)}})
$$

Так как удобнее минимизировать функцию, то:

$$
\mathcal{L}_{Logistic} = \log(1 + e^{-M^{(i)}})
$$

## Если спросят

- **Зачем:** максимум $\prod P(\mathrm{data}\mid w)$; для логрега это $\sum\log\sigma(M)$, лосс $\log(1+e^{-M})$.
- **Когда ломается:** кодировка $y\in\{0,1\}$ vs $\pm 1$ в формуле с отступом.
- **Путают с:** MAP (там ещё prior).
- **Фраза:** максимум правдоподобия = минус логистический лосс.
