# Multiclass Metrics

Рассмотрим случай [[Classification Metrics]] на несколько классов.

## Micro
Складываем все TP, FP, TN, FN и считаем по ним метрики. Показывает общую точность модели.

## Macro
Считаем метрики для каждого класса и потом берём среднее. Показывает среднюю точность модели по классам.

## Weighted
Считаем метрики для каждого класса и потом берём среднее, при этом учитывая количество объектов в каждом классе. Показывает среднюю точность модели по классам, при этом избегая большого влияния классов с малым количеством объектов.

## Confusion matrix
Матрица ошибок - это матрица, где на пересечении i-ой строки и j-ого столбца находится количество объектов, которые были классифицированы как i-ый класс, но на самом деле являются j-ым классом.

## Если спросят

- **Зачем:** micro — общая куча TP/FP; macro — среднее по классам; weighted — с размером класса.
- **Когда ломается:** micro прячет редкие классы; macro уравнивает маленький и большой.
- **Путают с:** бинарным precision без averaging.
- **Фраза:** micro — одна большая матрица, macro — каждый класс equally.
