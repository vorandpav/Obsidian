# Multiclass Classification

Для классификации на несколько классов мы можем использовать [[Logistic regression]].

## One vs Rest
Подход заключается в том, чтобы для каждого класса обучить свою модель, которая будет классифицировать только этот класс. Возникает проблема с линейно неотделимыми классами.

![[Pasted image 20260809173531.png]]

## One vs One
Подход заключается в том, чтобы для каждой пары классов обучить свою модель, которая будет классифицировать только эти два класса. Решает проблему с линейно неотделимыми классами, но возникает проблема с отнесением к классу точки, которая не принадлежит ни одному из классов. А также требует k(k-1)/2 моделей.

![[Pasted image 20260809173642.png]]

## Если спросят

- **Зачем:** OvR — $K$ моделей; OvO — $K(K-1)/2$ и закрывает линейную неотделимость.
- **Когда ломается:** OvR на классе «в середине»; OvO — дыры, куда точку не отнести.
- **Путают с:** softmax / одной совместной мультиномиальной моделью.
- **Фраза:** OvR дешевле, OvO дороже и без «среднего» класса.
